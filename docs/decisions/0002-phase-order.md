# 0002: Phase order

- **Date:** 2026-09-19
- **Status:** Accepted

## Decision
Phase 0 proves the gate on yespajak. Then 1 hardening, 1b Python, 2 frontend and mobile, 3 LLM evals, 4 fleet, 5 security and performance. Business logic before UI, gates before conveniences. Every phase lands on an adopter before it is called done.

## Consequences
Phases have exit criteria instead of dates (`docs/roadmap.md`). A phase whose criteria cannot be shown on an adopter is not done, however much engine code exists.
