# 0004: Canonical yespajak repo

- **Date:** 2026-10-01
- **Status:** Accepted

## Context
A local scaffold and the public `vinsonsid/yespajak` (the live app at yespajak.pandancoco.com) had unrelated histories.

## Decision
The public `vinsonsid/yespajak` is canonical. The engine was retrofitted onto it; the old scaffold is retired.

## Consequences
Every phase exit is shown on the live app's repo, behind real branch protection.
